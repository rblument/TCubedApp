# TCubed

Task Tracking Tool

In your NetBeans Project Properties, in the Run (on left) add, 
  MainClass Filed:  edu.regis.tcubed.TCubedApp
  VMOptions field:
    -DDB_URL=jdbc:mysql://localhost:3306/TCubedDB -DDB_USER=TCubedTs -DDB_PASSWORD=TCubed2026

Testing: Start a local Web Browser and enter the URL
   http://localhost:8080


The W-Web represents a port to a Web environment using Koyeb and Aiven MySQL.
